# 四叉树（Quadtree）

四叉树递归划分二维空间。以常见的区域划分方式为例，根节点覆盖整个矩形区域，每次沿两个坐标轴的中点切分，得到四个子区域。划分深度可以随数据变化，密集区域可以继续细分，稀疏区域可以较早停止。

四叉树可用于二维空间索引、图像分块和自适应网格。例如查找地图窗口内的点时，可以直接跳过与窗口不相交的子区域。

## 实现分类

- [构造](build/)涵盖将二维数据分配到四个子区域，再独立构建各子树。
- [查询](query/)涵盖定位点所在的单元，或在矩形窗口内查找数据。
- [重建](rebuild/)涵盖数据分布变化后，对局部区域重新细分或合并。

更多细节见 [CGAL 的八叉树与四叉树文档](https://doc.cgal.org/latest/Orthtree/index.html)
