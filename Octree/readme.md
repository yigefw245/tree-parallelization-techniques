# 八叉树（Octree）

八叉树递归划分三维空间。根节点覆盖整个三维区域，每次细分沿三个坐标轴的中点切分，将当前区域划为八个子区域。实现通常会限制树深，或在叶节点所含元素少于一定数量时停止细分。

不同区域可以细分到不同深度。这个特点适合组织密度不均的三维点云，也可用于体素数据和碰撞检测中的空间筛选。

## 实现分类

- [构造](build/)涵盖将三维点或体素分配到子区域，独立构建各子树。
- [查询](query/)涵盖查找点所在的单元，或跳过与查询盒不相交的区域。
- [重建](rebuild/)涵盖点云批量变化后重新划分受影响的区域。

更多细节见 [CGAL 的八叉树与四叉树文档](https://doc.cgal.org/latest/Orthtree/index.html)
