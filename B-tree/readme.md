# B 树与 B+ 树

两种树都是平衡的多路搜索树。节点按顺序存放多个键，所有叶节点位于同一深度。一个节点可以容纳多个键和子节点指针，因此树的层数通常较少，适合按页读写的索引。

- **B 树（B-tree）** 的内部节点和叶节点都可以存放键及对应的记录或记录引用。按键查找时，命中内部节点即可结束。它可用于在磁盘上维护大型有序索引。
- **B+ 树（B+ tree）** 的内部节点用分隔键引导查找，记录或记录引用都放在叶节点。叶节点通常按键顺序相连，范围查询可以定位起始键后沿叶节点顺序扫描。它常用于数据库索引。

## 实现分类

- [构造](build/)涵盖从一批键构建索引，例如并行排序后分组构建节点。
- [查询](query/)涵盖按键查找、范围扫描和批量查询。
- [重建](rebuild/)涵盖根据现有记录重新组织索引，例如批量删除后重新填充节点。

提交时请在实现目录的 README 中注明使用的是 B 树还是 B+ 树。

更多细节见 [Douglas Comer, The Ubiquitous B-Tree](https://g-trees.github.io/g_trees/assets/references/comer1979ubiquitous.pdf)
